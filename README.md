\# Healthcare Claims Analytics Pipeline



\*\*Python | DuckDB | SQL | Data Engineering | Data Analytics\*\*



\## Project Overview



An end-to-end healthcare claims analytics demonstration built with Python and DuckDB.



The project will demonstrate how raw claims transactions can be ingested, cleaned, validated, transformed, and analyzed to produce actionable business insights.



\*\*Data:\*\* Entirely synthetic records generated specifically for this portfolio project.



\## Business Questions



1\. How many claims are submitted each month?

2\. What percentage of claims are paid, denied, or pending?

3\. What is the average time between submission and reimbursement?

4\. Which claim categories have the highest denial rates?

5\. How do submitted and reimbursed amounts compare?



\## Technology Stack



\- Python — Data ingestion, cleaning, and automation

\- DuckDB — Local analytical database

\- SQL — Transformations, reconciliation, and analysis

\- Pandas — Data processing

\- Git and GitHub — Version control



\## Planned Pipeline



Synthetic Data Generation → Raw Data Ingestion → Data Validation → SQL Transformation → Analytics → Reporting



\## Project Status



Under development. Implementation, validation tests, and example results will be added progressively.



\## Data Privacy



This project does not contain real patient records, hospital database exports, or confidential institutional information.
